# 07 — Product Case Studies

These case studies demonstrate structured product reasoning using familiar industry workflows. They are reconstructed, synthetic portfolio artefacts. They do not reproduce confidential employer materials or claim that every diagram, endpoint or requirement was deployed in production.

## Case studies
1. [Travel booking API integration](travel-booking-api-integration.md) — supplier revalidation, booking states, uncertain outcomes and recovery.
2. [Healthcare laboratory integration](healthcare-lab-integration.md) — lab orders, result exchange, identity matching and exception handling.

## Suggested review lens
For each case, assess:
- User problem and business outcome.
- Actors and system boundaries.
- Requirements and acceptance criteria.
- API and data contract assumptions.
- Edge cases and operational risks.
- Candidate success measures and instrumentation.

Metrics are presented as candidate measures unless explicitly labelled as previously reported project/team outcomes.
